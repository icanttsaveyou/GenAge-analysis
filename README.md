# GenAge Project

Analysis of aging-related genes from the GenAge database (worms, flies, mice → human orthologs) and shared pathways (insulin/IGF-1, mTOR, FoxO, AMPK, etc.).

## Folder structure
```
GenAge_project/
├── data/                          # raw downloaded files
│   ├── genage_human.csv
│   ├── genage_models.csv
│   ├── human_homologs.csv
│   ├── human_genes.zip            (optional)
│   └── models_genes.zip           (optional)
├── scripts/
│   ├── genage_analysis.py         # main analysis script
│   └── download_data.sh           # optional download helper
├── results/                       # output files generated by the script
│   ├── model_genes_with_human_homologs.csv
│   └── pathway_enrichment_human_orthologs.csv
├── requirements.txt
└── README.md
```

## How to create this folder yourself (terminal)

```bash
# Create the project folder and subfolders
mkdir -p GenAge_project/{data,results,scripts}

# Move into it
cd GenAge_project

# Create a requirements file
echo -e "pandas\ngprofiler-official" > requirements.txt

# (Optional) Create the download helper
cat > scripts/download_data.sh << 'EOF'
#!/bin/bash
set -e
cd "$(dirname "$0")/../data"
curl -sL -o human_genes.zip https://genomics.senescence.info/genes/human_genes.zip
unzip -o human_genes.zip
rm -f human_genes.zip release.html
curl -sL -o models_genes.zip https://genomics.senescence.info/genes/models_genes.zip
unzip -o models_genes.zip
rm -f models_genes.zip release.html
curl -sL -o human_homologs.csv "https://genomics.senescence.info/genes/search.php?organism=Homo+sapiens&show=5&export=true&homologs=true"
echo "Done."
ls -lh
EOF
chmod +x scripts/download_data.sh
```

## How to run the analysis

1. Install requirements (from the project root):
   ```bash
   pip install -r requirements.txt
   ```

2. Make sure the three CSV files are in the `data/` folder  
   (either download them manually or run `bash scripts/download_data.sh`).

3. Run the analysis:
   ```bash
   python scripts/genage_analysis.py
   ```

Results will appear in the `results/` folder.

## Data sources
- GenAge human & model organism genes: https://genomics.senescence.info/download.html
- Human homologs export: https://genomics.senescence.info/genes/search.php?organism=Homo+sapiens&show=5&export=true&homologs=true

## Notes
- Focuses on *C. elegans*, *Drosophila*, and mouse genes that have human orthologs.
- Uses g:Profiler for pathway enrichment (KEGG, Reactome, WikiPathways, GO Biological Process).
- Strong enrichment is typically seen for insulin/IGF-1, mTOR, FoxO, AMPK, and longevity pathways.
